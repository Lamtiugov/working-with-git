## Приложение git

### Установка

Установка зависит от операционной системы. Легко ищется в любом поисковике.

### Настройка локального Git

Базово надо прописать имя и свою почту.
Для этого выполняем такие команды в консоли:

```
git config --global user.name "Кем тебя будут видеть"
# имя или ник нужно написать латиницей и в кавычках

git config --global user.email username@yandex.ru
# здесь нужно указать свой настоящий email
```

Проверяем командой консоли

```
git config --list 
```

## Работа с GitHub
### Регистрация

Про ссылке [GitHub](https://github.com/) регистрируем account по инструкции на сайте. Нужна будет актуальная почта.

### Создание удаленного репозитория

Заходим в свой профиль. Ссылка вида https://github.com/username, где username — имя, которое указали при регистрации.
Для этого перейдим на вкладку Repositories, а затем нажмём на зелёную кнопку New справа.
В открывшемся окне "Create new repository" даем имя, например, first-project, выставляем опцию "Add README" в "ON" и жмем "Create repository".

### Создание SSH-ключей

Если уже есть ключи - пропускаем.
Если нет, то создаем, следуя инструкции команды ниже.

```
ssh-keygen -t ed25519 -C "электронная почта, к которой привязан аккаунт на GitHub"
```

Если не сработает, то другой командой

```
ssh-keygen -t rsa -b 4096 -C "электронная почта, к которой привязан аккаунт на GitHub"
```

В хомяке в скрытой папке .ssh появятся 2 файла: без расширения и с расширением .pub. Например, id_ed25519 и id_ed25519.pub

### Привязываем SSH-ключ к GitHub

Копируем содержимое публичного SSH-ключа в буфер обмена.
Переходим на GitHub и выбераем пункт Settings в меню аккаунта.
В меню слева нажмаем на пункт SSH and GPG keys.
В открывшейся вкладке выбераем New SSH key.
В поле Title напишем название ключа. Например, Personal key.
В поле Key type должно быть Authentication Key.
В поле Key копируем ключ из буфера обмена.
Нажем на кнопку Add SSH key.

Чтобы проверить правильность ключа запускаем (надо будет подтвердить, что хотим соединиться с сервером)

```
ssh -T git@github.com
```

## Локальный git-репозиторий

Заводим папку, где будут лежать проекты, например, "C:\Sources".
Заходим в созданный репозиторий, например, https://github.com/username/first-project.
Жмем на зеленую кнопку "Code", выбираем закладку SSH, жмем кнопку "Copy URL to clipboard"
На рабочей машине заходим в папку консолью и выполняем:

```
git clone ссылка на репозиторий из буфера обмена
```

В папке  проектами появится папка, например, "first-project".

## Команды git

```
git config --list   # Показывает полный конфиг git
git init    # создать репозиторий
git status  # состояние текущего репозитория
git add .   # подготовили к сохранению все файлы в репозитории
git add todo.txt    # подготовили к сохранению конкретный файл в репозитории
git commit -m ‘Мой первый коммит!’  # появится коммит с комментарием "Мой первый коммит!"
git log # история коммитов
git remote add origin git@github.com:%ИМЯ_АККАУНТА%/first-project.git   # привязать удаленный репозиторий
git remote -v   # проверить связь локального и удаленного репозитория
git push    # отправить на удаленный репозиторий
git pull    # взять изменения с удаленного репозитория
git clone   # взять удаленный репозиторий
```

Посмотреть можно на сайте [документации](https://git-scm.com/docs)
