## Работа с GitHub
### Регистрация

Про ссылке [GitHub](https://github.com/) регистрируем account по инструкции на сайте. Нужна будет актуальная почта.

### Создание удаленного репозитория

Заходим в свой профиль. Ссылка вида https://github.com/username, где username — имя, которое указали при регистрации.
Для этого перейдим на вкладку Repositories, а затем нажмём на зелёную кнопку New справа.
В открывшемся окне "Create new repository" даем имя, например, first-project, выставляем опцию "Add README" в "ON" и жмем "Create repository".

### Создание SSH-ключей

Если уже есть ключи - пропускаем.
Если нет, то создаем, следуя инструкции команды ниже.

```
ssh-keygen -t ed25519 -C "электронная почта, к которой привязан аккаунт на GitHub"
```

Если не сработает, то другой командой
```
ssh-keygen -t rsa -b 4096 -C "электронная почта, к которой привязан аккаунт на GitHub"
```

В хомяке в скрытой папке .ssh появятся 2 файла: без расширения и с расширением .pub. Например, id_ed25519 и id_ed25519.pub

### Привязываем SSH-ключ к GitHub
